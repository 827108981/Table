========================================
迈瑞技术支持驾驶舱 - 使用说明
========================================

【系统要求】
- Windows 7/8/10/11 (64位)
- 首次运行需要联网
- 建议内存：4GB以上

【首次使用】
1. 双击运行"迈瑞技术支持驾驶舱.exe"
2. 首次运行会自动下载浏览器组件（约100MB），请耐心等待
3. 程序启动后会自动打开浏览器显示驾驶舱界面

【功能说明】
- 自动登录MSPS系统并爬取工单数据
- 每10分钟自动更新一次数据
- 实时展示工单分布地图
- 自动生成超时工单报表

【注意事项】
1. 首次运行需要在弹出的Edge浏览器中手动登录MSPS账号
2. 登录后按回车键确认，后续运行会自动保持登录状态
3. 程序会在当前目录创建"工单报表数据"文件夹存储数据
4. 关闭控制台窗口即可停止程序

【常见问题】
Q: 程序无法启动？
A: 请确保有网络连接，首次运行需要下载浏览器组件

Q: 数据显示不出来？
A: 请检查是否已成功登录MSPS系统

Q: 如何修改数据刷新间隔？
A: 目前设置为10分钟，如需修改请联系开发人员

如有问题，请联系系统管理员
